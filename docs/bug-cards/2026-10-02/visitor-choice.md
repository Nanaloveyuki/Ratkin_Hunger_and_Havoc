# 访客选择信失效与裸翻译键

| 字段 | 内容 |
| --- | --- |
| 复现 | 打开访客信，改变来客身份/闸门后点击拘捕、奴役；关闭雇佣与加入门禁后查看攻击 |
| 期望 / 实际 | 按实际资格执行并明确失败原因；实际选项一次禁用后不会刷新，失败也先关闭窗口，缺失键直接显示 |
| 版本 | 1.0.0，基线 60967e8，未正式发布 |
| 级别 | S2 |
| 根因 | 选择信把招募资格当攻击资格，把门禁关闭当检疫；招募与实际留驻使用不同闸门；检疫原因忽略设置；DiaOption.resolveTree 在 action 前关窗；动态默认原因缺翻译；已有麻醉时原版合并会丢弃新实例 |
| 最小修复 | 招募和加入检查 JoinColony，雇佣检查 Hire；真实检疫并尊重封锁加入设置；拘捕直接转换并麻醉 12 小时，奴役直接转换并将 will 置 0；点击重新检查，失败留信留窗，成功才关闭；补中英原因 |
| 麻醉契约 | 优先复用已有 Anesthetic，否则添加原版实例；对健康列表中实际保留的实例设 severity=1、既有消失组件 30000 tick 和 severityPerDay=-0.2，不追加重复组件。半天仍高于昏迷阈值 0.8，时限和衰减都由原版组件保存 |
| 明确不做 | 不取消检疫和身份限制，不搬运，不改到期机制；不伪造个人奴役历史事件 |
| Language | NoRecruit、NoIdeology 等原因中英补齐；拘捕提示改为原地转换及麻醉 |
| 存档 | 无迁移或破坏性重建 |
| 归属表 | 不变 |
| 回归 | 既有资格、拒绝和结算回归通过；实际 DiaOption.Activate 失败保留访客信及窗口，六个相关键双语实际 Translate 通过。拘捕成功路径已实际推进到原版身份转换和添加麻醉；完整麻醉及奴役成功 smoke 未完成，按用户要求停止继续运行，改以原版转换和组件存读实现静态审查验收 |
| 后续债 | 其它选择信同根因另卡修复，不借此更改剧情 |
