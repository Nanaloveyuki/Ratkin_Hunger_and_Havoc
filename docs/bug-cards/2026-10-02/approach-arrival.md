# 世界队伍到达与读档

| 字段 | 内容 |
| --- | --- |
| 复现 | 地图事件队伍出现在世界后保存退出再加载，到达时地图温度或入场条件暂不满足 |
| 期望 / 实际 | 后续生成保留；实际到达调用失败也立即销毁唯一事件持有物 |
| 版本 | 1.0.0，基线 60967e8，未正式发布 |
| 级别 | S2 |
| 根因 | WorldObject_RHAH_Approach.Arrive 无条件 Destroy，且把已保存的 mapId 改成 Home 查询的结果 |
| 最小修复 | 到达返回成功、等待或终止；等待按游戏小时保留队伍并保存剩余冷却，异常或永久失效明确终止。沿用自有调度和 Worker.TryExecute 的入场判断，不叠加原版事件类别难度限制，避免和平难度下非战斗 ThreatBig 队伍永远等待 |
| 明确不做 | 不改世界 Pawn 保存，不保存长期未入场商队 Pawn，不恢复已经被销毁的队伍 |
| Language | 无 |
| 存档 | 新增 arrivalPending=false；使用原 costLeft 保存到达等待剩余 tick，无改键或破坏性重建 |
| 归属表 | 更新队伍字段说明；已有 Remove 归属覆盖 |
| 回归 | 真实到达调用失败前后 smoke；Scribe 保存加载待到达状态，覆盖重复生成和永久失效；商队沿用原版同步生成路径 |
| 后续债 | Unity 内完整生成及地图排版仍须实机确认 |

## 验证结果

- Release 主体及 API 构建：0 警告、0 错误
- 原始真实 Arrive 离线探针：运行组件缺失时仍请求销毁；修复后不销毁，arrivalPending=true
- 原版 Scribe 保存/完整加载阶段烟雾：到达失败保留事件，一小时冷却；保存后加载保留 1024 tick、地图 41 和点数 300；下一次 64 tick 后剩余 960，未重新寻路
- 世界物体完整存读的临时运行副本仅移除 Unity 绘图静态初始化并将原版日志转到控制台，所有实例方法和本模组程序集不变；不等同于 Unity 游戏内验证
- 真正玩家商队 I-035/I-050 仍由原版同步生成攻击地图，未引入悬置 Pawn 存档字段；游戏现场未运行
