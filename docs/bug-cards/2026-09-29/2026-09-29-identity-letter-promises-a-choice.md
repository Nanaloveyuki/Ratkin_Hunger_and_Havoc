# 身份开关承诺了不存在的拒绝

| 字段 | 内容 |
| --- | --- |
| 复现 | 1.0.0。结局页打开身份询问。信任到门槛后，穗音叙事下直接收到一封中立信 |
| 期望 / 实际 | 期望提示只说明实际会发生的事。实际提示写“拒绝不扣信任，也不会再问”，游戏里没有拒绝入口，到期直接 `MarkIdentity(offer, false)` |
| 版本 | 1.0.0 |
| 级别 | S2 |
| 根因 | 设置文案和开发者预览仍是旧的询问信。运行时只发已经决定好的部分或完整身份 |
| 最小修复 | 提示改成自动告知。开发者预览按当前信任显示将要发出的那一档 |
| 明确不做 | 不补接受或拒绝选择信。不改 `identityRefused`、信任和发信时机 |
| Language | `RHAH_Ending_Identity`、`RHAH_Ending_Identity_Tooltip` |
| 存档 | 无 |
| 归属表 | 否 |
| 回归 | 预览在完整信任门槛用完整身份，其下用部分身份。询问键不再被结局预览引用 |
| 后续债 | 无 |
