# 事件来客在地图边缘徘徊

| 字段 | 内容 |
| --- | --- |
| 复现 | 在玩家居住区远离地图边缘的存档中触发鼠族访客事件，观察没有可用乞讨或取食任务的可行动来客；来客在入场边缘徘徊 |
| 期望 / 实际 | 可行动来客入场后前往玩家居住区附近，再寻食、乞讨或等待 / 赶路与寻食职责以入场格为目的地，来客会在边缘附近等待和游荡 |
| 版本 | 1.0.5 开发版 |
| 级别 | S2 |
| 根因 | 事件、生成与重新建组入口均把 `SpawnCell` 或来客当前位置传入 `RHAH_VisitorGroup.TryStart`，后者直接用作 Lord 的 `waitSpot`。入场格与停留格没有分离；无赈灾区时断粮等待也直接使用当前位置 |
| 最小修复 | 在访客赶路职责中选择玩家居住区附近、来客按自身开门规则可达的停留格，赶路和寻食共享该目的地；断粮等待无可达赈灾点时向访客停留点靠拢。覆盖旧档已有边缘目的地；集合到达仅等待可自行移动的成员，倒地与不能自行移动的幼年成员继续保留在照护 Lord |
| 明确不做 | 不改变乞讨成功率、取食资格、袭击或拦截 Lord，不开门穿墙，不瞬移，不增加常驻全图扫描，不改变选择投喂后的原地等待 |
| Language | 无 |
| 存档 | 无，不新增或改名 Lord、Comp 存档键；现有 `waitSpot` 和赶路目的地保存修正后的位置 |
| 归属表 | 否 |
| 回归 | 已完成管理层烟测：边缘入场选择居住区附近室外可达点、受限关闭门不穿越、旧边缘职责刷新、倒地成员不阻塞可行动成员进入寻食、无赈灾区时向停留点靠拢、无居住区时仍有可达回退。玩家复测：在居住区远离边缘的存档触发普通访客与家庭事件，并载入已有边缘来客的旧档观察移动 |
| 后续债 | 真实游戏中的整批到达、家庭抱持及实际移动待玩家复测；管理层烟测不覆盖 Unity 动画 |
