# 饥民开门设置误限制短工和长工

| 字段 | 内容 |
| --- | --- |
| 复现 | 在有本模组事件来客的存档中关闭「允许饥民开门」，收留来客为短工，再指派其执行需要经过门的工作；长工使用同一路径 |
| 期望 / 实际 | 仅本模组五个态度派系的非玩家来客受此设置限制，短工、长工和殖民者沿用原版开门规则 / 来源标记仍活跃的短工、长工也被补丁拒绝开门 |
| 版本 | 1.0.5 开发版 |
| 级别 | S2 |
| 根因 | `RHAH_DoorPatch.Postfix` 只检查 `RHAH_Api.IsVisitor`；临时停留保留来源标记与活跃生命周期，却已转入玩家派系。补丁没有检查当前派系，也没有限定五个态度派系 |
| 最小修复 | 原版允许开门后，先排除玩家、无派系与非五个态度派系，再沿用来源标记、设置与地图威胁条件 |
| 明确不做 | 不改 `IsVisitor`、临时停留生命周期、短工长工计时、疾病补丁或原版门的权限 |
| Language | 无，现有设置说明语义不变 |
| 存档 | 无，现有存档直接按当前派系生效 |
| 归属表 | 否 |
| 回归 | 已完成管理层验证：真实开门补丁拒绝设置关闭时的态度派系来客，允许玩家短工开门；原版区域寻路拒绝穿过受限的关闭门。玩家复测：关闭设置，分别让短工、长工经过关闭的门执行工作，再确认五个态度派系的来客仍受限制 |
| 后续债 | 真实游戏中的短工、长工通行待玩家复测；管理层烟测不覆盖 Unity 动画与实际移动 |
