# 访客选择信的俘虏与奴役

| 字段 | 内容 |
| --- | --- |
| 复现 | 现有存档或新游戏触发 I-004 等访客选择信；使用送进监狱；关闭目标 Imprison 闸门后使用俘虏；同批部分来客已收留时使用俘虏或奴役 |
| 期望 / 实际 | 只转换本图、本批、仍在活动的合格访客，成功后才关闭选择；实际送进监狱脱图后丢失地图，按钮与执行闸门不同，全批跳过仍结算，已释放角色也进入转换名单 |
| 版本 | 1.0.0，未正式发布 |
| 级别 | S1，送进监狱可能使角色脱图后不能重新生成 |
| 根因 | DeSpawn 后读取 MapHeld/Map；展示使用 Hire/JoinColony、执行使用 Imprison；执行使用全部记录角色而非当前访客；先写 settled 再执行且忽略 ReleaseToColony 返回值 |
| 最小修复 | 删除 Prison 按钮、搜格、瞬移与动作；俘虏保留原地身份转换，仅允许已处于封闭囚室的访客；统一按钮与执行资格，实际转换至少一人后才结算；释放拒绝时不改 Lord、派系或身份；奴役清隐藏原派系、解锁衣物并通知奴役历史事件 |
| 明确不做 | 不增加押送 Job、不抑制原版越狱、不部署、不改外部模组、API 签名、包名或事件 ID；不修其它加入、停留和交易动作的事务 |
| Language | 删除 RHAH_Choice_Prison；修改 Capture/Enslave 标签；新增囚室限制、无合格目标、转换失败提示，中英成对 |
| 存档 | 迁移：settled 的旧文本 Prison 和旧数值 12 读为 Capture；其它名称、数值和键不变，无新持久化字段；已脱图角色不猜测恢复 |
| 归属表 | 更新 settled 的迁移说明，卸载动作不变 |
| 回归 | 本图本批筛选、已释放/玩家派系/精神状态排除、Imprison 优先、封闭囚室与开门边界、释放策略拒绝无变更、全部失败保留信、重复结算、旧 settled 存读；临时烟雾程序调用实际实现 |
| 后续债 | 选择信没有实际奴役执行者，历史事件只记录受害者，不伪造殖民者 Doer；因此不产生指定执行者的个人戒律心情或次数记录。转换后正常越狱和解放继续走原版 |

俘虏只转换已在囚室里的合格来客，不搬运。囚室必须不接地图边缘，边界不能有可自由通行的门；即使门外只是走廊也拒绝，采用保守限制。倒地来客可以转换，不额外要求能自行行走。检疫中的来客不通过选择信俘虏或奴役；原版拘捕仍只问 Imprison。混合批次仅转换合格成员，其余保持原状，至少成功一人才结算。

## 验证结果

- `python3 scripts/verify-scaffold.py` 通过，中英键与存档归属检查通过
- 针对俘虏资格、结算、原版 gate 与选择记录存读的 44 个用例通过；完整测试程序集 382 个用例通过
- 临时 Mono 烟雾程序调用当前实现：封闭囚室允许、Hire/JoinColony 拒绝不影响囚禁、室外失败保留位置身份和选择、释放策略拒绝、已释放角色排除、奴役无目标不结算、超时优先与重复拒绝均通过
- 成功的原版 `CapturedBy` / `SetGuestStatus`、奴隶历史事件和实际游戏选择窗口尚未在 Unity 游戏内验证。烟雾覆盖真实资格、拒绝和结算路径，不以伪造转换替代游戏内验证
