# 鼠妈生完后可遗传基因遗失

| 字段 | 内容 |
| --- | --- |
| 复现 | 生物科技开启。鼠妈是可遗传异种，基因在原初基因组。她带多崽分娩，或没有父亲时生下新生儿 |
| 期望 / 实际 | 期望孩子继承母亲的可遗传异种，基因留在原初基因组。实际多出来的幼崽按普通生成，鼠族基因进了异种基因组，原版只继承内源基因，孩子看起来基因异常遗失 |
| 版本 | 0.1.0 |
| 级别 | S1 |
| 根因 | `RHAH_LargeLitterPatch` 给多出来的幼崽只传种类、派系和新生儿阶段。原版正式新生儿会强制内源基因和可遗传异种。没有父亲且母亲异种可遗传时，原版也不会把异种写到孩子身上。异种基因不进 `GetInheritedGenes` |
| 最小修复 | 抽出多崽生成请求，按原版新生儿写入父母内源基因，并在可继承时写入异种。分娩后把正式孩子和多出来的幼崽都收成可遗传原初基因组 |
| 明确不做 | 不重抽父母没有的基因。不改早熟、高育、速产和乱起。不改基因页权重 |
| Language | 无 |
| 存档 | 无 |
| 归属表 | 否 |
| 回归 | `LitterRequestKeepsHeritableGenesAsEndogenes`。多崽请求带父母内源基因和可遗传异种，不带异种基因。没有父亲的可遗传母亲也会写上异种 |
| 后续债 | 已经出生、基因已在异种基因组里的孩子不回写 |
