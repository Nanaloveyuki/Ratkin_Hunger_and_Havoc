# 灾鼠名字混入人类名库

| 字段 | 内容 |
| --- | --- |
| 复现 | 新游戏触发一批灾鼠，看整批名字 |
| 期望 / 实际 | 期望整批都用鼠族名字规则。实际一群里会夹几个人类名 |
| 版本 | 0.1.0 |
| 级别 | S2 |
| 根因 | 原版 `GiveAppropriateBioAndNameTo` 在非婴儿、未强制背景时有 25% 直接套固定传记，名字来自人类实名库，不再问种族 `nameGenerator`。态度派系的背景过滤器是 `Outlander`，固定传记能匹配。没抽中时，种族 `nameGenerator` 又排在异种名库和背景名库后面，而 `Ratkin` 继承人类 `nameCategory`，两者都空时还会落到人类洗牌名库 |
| 最小修复 | 本模组生成请求固定 `ForceNoBackstory`，跳过固定传记。生成后若种族有 `nameGenerator`，用它重写名字。多出来的幼崽走同一条 |
| 明确不做 | 不改已经在场的人。不改态度派系的 `Outlander` 过滤器。不改调用方传入的非鼠族种族。不给没有 `nameGenerator` 的种族造名字 |
| Language | 无 |
| 存档 | 无。名字仍写在原版 pawn 名字字段 |
| 归属表 | 否 |
| 回归 | `RHAH_RatkinNameTests`：有种族名库就重写，没有就不改，显式背景仍强制跳过原版背景 |
| 后续债 | 无 |
