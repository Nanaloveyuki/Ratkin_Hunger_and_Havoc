| 字段 | 内容 |
| --- | --- |
| 复现 | 玩家反馈：事件鼠族到达后，在选择信点攻击，来客直接撤离而未变红。事件编号、存档与设置未提供；按实际反馈定位，不重复要求玩家复现 |

| 版本 | 当前 1.0.0 源码，未正式发布 |
| 级别 | S1 |

| 最小修复 | Source/Pawn/RHAH_BatchAttitude.cs：显式攻击只命令不允许 Fight 的成员离场，允许者保留原生命周期与访客 Lord；转敌对同步校正玩家关系和相关地图目标缓存 |
| 明确不做 | 不创建袭击 Lord，不改伤害/驱逐的离场策略，不绕过 Fight，不自动回滚已经离场的旧选择，不部署，不改公开 API 或无关文案 |
| Language | 无，现有中英“攻击（整批转为敌对）”仍适用，关闭反击的既有说明不变 |
| 存档 | 无新键、无迁移或破坏性重建；保持现有来源、Lord 与生命周期存读格式 |
| 归属表 | 不更新，无新增持久化类型或键 |
| 回归 | Release 测试项目构建成功，0 error、4 条既有 xUnit2013 warning；结构/双语/存档契约检查通过。Mono 运行真实 TrySettle + Apply：6 个攻击场景全部通过，另 4 个既有态度策略回归通过。修复前已观察默认攻击把 SeekingFood 写成 Leaving，玩家关系修复断言失败；修复后直接烟测输出 choice=Attack、attitude=Neutral → Hostile、lifecycle=SeekingFood → SeekingFood |
