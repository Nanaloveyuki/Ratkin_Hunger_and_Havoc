# 排队事件丢失原始目标

| 字段 | 内容 |
| --- | --- |
| 复现 | 0.1.0 新游戏。玩家家园和商队同时存在时，讲述者按某个家园或某支商队抽中事件；IrisMenus 或通讯台入队后，观察执行时的地图或商队 |
| 期望 / 实际 | 期望执行仍打向入队时的那张地图或那支商队。实际队列只存显示 ID，执行时 `RHAH_MapResolver.Resolve()` 与 `CaravanTargetResolver.ResolvePlayerCaravan()` 重新随机。目标暂时找不到时队首直接返回，后面目标仍可用的事件也被拖住。目标已销毁时仍按“无地图”无限等待 |
| 版本 | 0.1.0 |
| 级别 | S1 |
| 根因 | 入队没有保存原始 `Map.uniqueID` 或 `Caravan.ID`。执行把“还没加载”和“已经不存在”都当成同一种等待，并且只检查队首 |
| 最小修复 | 队列追加 `pendingIncidentTargetIds`。Map 存正数 `uniqueID`，Caravan 存负数 `-ID`，0 表示未指定。执行只解析保存的目标。目标暂时不可用时保留该项并尝试下一项；目标永久失效、目录缺失、Def 缺失或 Worker 确定失败时只丢弃该项。未指定目标保持旧的随机解析 |
| 明确不做 | 不改事件显示 ID、Def、点数、权重、商队生成语义或公开 API。不改 Pawn 生命周期、叙事、信任或 Journal。调试入队仍先用现有随机解析确认目标存在，再保存那一次选中的 ID。通讯台广播的目标是控制台所在地图，不改广播候选 |
| Language | 无 |
| 存档 | 新键 `pendingIncidentTargetIds`。与显示 ID 等长。旧档缺列表时按 0 补齐，0 保持未指定并走旧随机解析。空列表与 null 都是空队列 |
| 归属表 | 是。`GameComponent_RHAH_Game` 增加该键，卸载动作为 Remove |
| 回归 | 两个地图 ID 入队后执行顺序和目标都不被重选；暂时不可用的队首保留，后面可用目标先执行；永久失效只丢弃失效项 |
| 后续债 | Worker 内部若忽略 `IncidentParms.target` 再次随机选商队，不在本次改。未指定目标的旧随机解析仍保留，供旧档和没有目标的调用 |
