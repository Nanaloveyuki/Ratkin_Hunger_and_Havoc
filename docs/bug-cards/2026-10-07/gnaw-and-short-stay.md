# 2026-10-07 啃食伤害、乞讨骚扰和短工衣物

| 字段 | 写什么 |
| --- | --- |
| 复现 | 在启用高耐久建筑材料的地图触发饥民来客，让其啃墙；让同一来客多次向殖民者乞讨并被打巴掌；选择“收为短工”并观察其衣物脱卸行为 |
| 期望 / 实际 | 期望每次啃树皮或墙皮只扣除固定耐久，树和墙各搜一次后选最近可达目标，失败单独冷却一游戏小时；被打到两次巴掌后暂停乞讨，饥饿低于 30% 时优先自救啃食，获赠或吃完真实食物后清掉巴掌数；短工开始时按设置锁定当时衣物，结束或永久身份转换只解开本模组加上的锁。实际原版伤害倍率会放大高耐久材料上的单次啃食，目标选择偏向树，失败冷却和赈灾寻食混用，乞讨没有巴掌后的自救，短工不锁衣物 |
| 版本 | 1.0.0，2026-10-07 |
| 级别 | S1 |
| 根因 | 啃食把固定值交给 `Thing.TakeDamage`，原版继续乘建筑和目标伤害倍率；目标搜索按类型固定顺序，失败冷却和赈灾寻食共用；乞讨只记录目标集合，不记录实际巴掌次数；短工开始没有锁定当时衣物，结束清理也不能只解开本模组加上的锁 |
| 最小修复 | 按设置直接扣除固定耐久并保留正常销毁；树和墙各搜索一次，选最近可达目标，失败写入 `gnawSearchUntilTick`，冷却一游戏小时。`begSlapCount` 达到 2 后暂停乞讨，饥饿低于 30% 时优先自救啃食；其它来客仍低于 5% 且普通食物、赈灾取食都失败才啃。成功获赠或吃完真实食物把巴掌数清回 0。`shortStayLockApparel` 默认开启，只在短工开始时锁定当时衣物，引用写入 `shortStayLockedApparel`；短工结束或永久身份转换只解开这些引用，不调用 `UnlockAll`。已保存的自定义啃食值保留，关闭锁衣物不追溯当前短工 |
| 明确不做 | 不改普通殖民者饮食、原版建筑伤害、乞讨成功率和打巴掌概率；不新增全图轮询；不改变加入殖民地、雇佣、俘虏和奴役规则；不扩展啃食到非树木植物 |
| Language | 中英日新增 `RHAH_Settings_ShortStayLockApparel` 与 `RHAH_Settings_ShortStayLockApparel_Tooltip`。四条啃食 tooltip 改为树 0.25/12、墙 0.20/10，并说明伤害是固定耐久扣除 |
| 存档 | `CompRHAH_Pawn.begSlapCount` 为 int，默认 0。`shortStayLockedApparel` 为衣物引用列表，默认空，归属 Remove。`gnawSearchUntilTick` 为 int，默认 -1。旧档缺键按默认值。1.0.0 前实验性存档直接补默认值，已保存的自定义设置不改 |
| 归属表 | 是。登记 `begSlapCount`、`shortStayLockedApparel`、`gnawSearchUntilTick` 的 Remove 归属，以及 `RHAH_Settings.shortStayLockApparel` 和四项啃食默认值 |
