# 2026-10-07 母亲可以按普通到来年龄生成到 1 岁以下

| 字段 | 写什么 |
| --- | --- |
| 复现 | 普通到来年龄保持默认 0 到 50，触发 I-003、I-004、I-029 或 I-044。对照同批幼年角色。来自源码对照，尚未游戏内复现 |
| 期望 / 实际 | 期望母亲和乞讨的母亲至少 14 岁，并可在 1 到 14 之间调整。实际未指定年龄时直接使用普通到来区间，可以生成到 0 岁 |
| 版本 | 本仓库 1.0.0，2026-10-07 当前工作树 |
| 级别 | S2 |
| 根因 | `RHAH_VisitorRules.GenerationAge` 对 `Mother` 和 `BeggarMother` 没有单独下界。事件没有传入固定年龄 |
| 最小修复 | 新增全局 `minMotherAge`，默认 14，范围 1 到 14。只抬高这两种角色未指定年龄时的生成下界。普通下限更高时用普通下限。上界更低时固定为下界。中英日文案、两处年龄设置、原版设置页、文档和归属表同步 |
| 明确不做 | 不改幼年角色、空投年龄、难民营成年年龄和已指定年龄。不改早熟受孕年龄。不清理全局设置，不改已发布存档键 |
| Language | 修改 `RHAH_Settings_Age_Tooltip`、`RHAH_Settings_YoungAge_Tooltip`。新增 `RHAH_Settings_MotherAge`、`RHAH_Settings_MotherAge_Tooltip`，中英日成对 |
| 存档 | 新增全局 `RHAH_Settings.minMotherAge`，默认 14。旧档缺键读默认，不迁移 |
| 归属表 | 是 |
| 回归 | 规则测试覆盖默认 14、设为 1、普通下限更高、上界更低时固定为下界，以及乞讨者和幼年角色不受影响 |
| 后续债 | 游戏内仍需看 I-003、I-004、I-029、I-044 的实际生成年龄 |
