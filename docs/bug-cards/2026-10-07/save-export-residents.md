# 卸载导出保留有地图地点的居民引用

| 字段 | 内容 |
| --- | --- |
| 复现 | 存档中存在已生成地图的 `RHAH_RefugeeCamp` 或 `RHAH_RecordSite`，并在世界物体保存 `residents` 引用，执行“备份并导出卸载用副本” |
| 期望 / 实际 | 期望保留地点 ID、地图父引用和居民引用；实际地点转换为原版 `Site` 时无条件删除 `<residents>`，导致地点仍有地图但丢失居民引用 |
| 版本 | 1.0.0，未正式发布 |
| 级别 | S1 |
| 根因 | `RHAH_SaveCleanup.ConvertCamp` 把 `residents` 当作仅属于本模组的运行时字段删除；卸载契约要求有地图或居民的地点保留居民引用 |
| 最小修复 | `ConvertCamp` 保留 `<residents>`，继续删除本模组地点部件、清理状态字段并替换地图生成器；测试覆盖已生成难民营的居民引用 |
| 明确不做 | 不改变居民 Pawn、地图、地点 ID 或地图生成器替换；不迁移居民到其它世界物体；不修改无地图且无居民地点的删除规则 |
| Language | 无 |
| 存档 | 无新增字段；保留既有 `residents` 引用 |
| 归属表 | 无新增持久化产物；同步补登记当前遗漏的 RHAH Def |
| 回归 | 清理后的已生成地点保留 `residents`，地点部件、清理状态和本模组类型仍被删除；无地图且无居民地点仍删除；二次清理保持不变 |
| 后续债 | 原版 `Site` 读档后是否继续消费该字段需真实游戏加载、运行、保存、再加载确认；本卡不改变地点居民的玩法归属 |
