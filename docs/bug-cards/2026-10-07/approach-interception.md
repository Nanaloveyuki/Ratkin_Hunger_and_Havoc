# 事件远行队拦截

| 字段 | 内容 |
| --- | --- |
| 复现 | 派玩家远行队与 `RHAH_Approach` 到同一个地表格，右键鼠族远行队 |
| 期望 / 实际 | 允许「拦截鼠族」并进入临时遭遇地图 / 当前没有右键选项 |
| 版本 | 1.0.4 开发版 |
| 级别 | S2 |
| 根因 | 世界物体未实现原版 `GetFloatMenuOptions(Caravan)`，事件生成尚未绑定临时地图事务 |
| 最小修复 | 世界物体菜单；原版临时遭遇地图生成与进入；成功生成后消费事件世界物体 |
| 明确不做 | 追踪、预约拦截、穿梭机拦截、强制改变鼠族态度 |
| Language | `RHAH_Approach_Intercept`、`RHAH_Approach_InterceptBlocked`、`RHAH_Approach_InterceptFailed`，中英日对称 |
| 存档 | 无新键、无迁移；地图父物体用原版 `AttackedNonPlayerCaravan`，地图与 retainedCaravanData 用原版 Scribe |
| 归属表 | 登记拦截地图保留原版父物体、地图和殖民者；清理沿用身份、Lord、信件、组件归属 |
| 回归 | 同格/异格/停用/太空/重叠菜单；进入后保存、读档、重组远行队；临时地图卸载导出保留殖民者与原版地图父物体 |
| 后续债 | 真实游戏的地图生成、自动保存和卸载副本加载需在游戏中验证 |

使用 LongEvent 完成地图生成、原事件执行、事件世界物体消费与玩家远行队进入。失败时，玩家仍留在世界远行队，未成功生成的地图删除，事件远行队保留。成功后不再向原家园重复生成。
