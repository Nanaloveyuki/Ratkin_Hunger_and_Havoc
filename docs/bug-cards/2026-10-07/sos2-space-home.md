# SOS2 轨道船被当成地面家园

| 字段 | 内容 |
| --- | --- |
| 复现 | 启用 Save Our Ship 2，玩家家园是 `ShipOrbiting`，生物群系 `OuterSpaceBiome`。太空远行队开关保持默认关闭 |
| 期望 / 实际 | 轨道船和奥德赛空间层一样，默认不抽事件、不生成远行队、不跑地图事件链。打开设置后才允许。实际只检查 `PlanetLayerDef.isSpace`，SOS2 船贴在行星格上，被当成普通玩家家园 |
| 版本 | 1.0.3 源码，未正式发布 |
| 级别 | S1 |
| 根因 | SOS2 用 `OuterSpaceBiome` 标记太空地图，不使用奥德赛空间层。本模组的家园过滤只认空间层 |
| 最小修复 | 家园是否在太空改为空间层或生物群系 `OuterSpaceBiome`。调度、远行队选家、行走和事件链共用这一判断，仍由 `spaceApproachEnabled` 放行 |
| 明确不做 | 不引用 `SaveOurShip2` 类型。不改 SOS2 穿梭机起飞，不拦奥德赛以外的发射。不改鼠疫、结局和特使的落点 |
| Language | 改中英日的太空家园说明，键不变 |
| 存档 | 无 |
| 归属表 | 否 |
| 回归 | 规则测试：`OuterSpaceBiome` 在开关关闭时不是家园，打开后是；地面生物群系仍是 |
| 后续债 | 未启动 SOS2，未部署 |
