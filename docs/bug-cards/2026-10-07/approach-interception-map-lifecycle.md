# 拦截地图生成后连锁异常

| 字段 | 内容 |
| --- | --- |
| 复现 | 1.0.4 开发版存档，玩家远行队与鼠族事件远行队在同一地表格，点击「拦截鼠族」；用户 Player.log 2535–2585 行记录 I-032、TileId 1309、生成 map uniqueId=1 后删图异常 |
| 期望 / 实际 | 玩家和鼠族进入同一张临时遭遇地图 / 玩家留在世界远行队，临时地图销毁中断并持续报植物、雾、沙、雪绘制错误 |
| 版本 | 1.0.4 开发版 |
| 级别 | S1 |
| 根因 | 日志事件是 I-032。RHAH_IncidentFacts.Submit 给空投 pawn 同时传 Map 和 IntVec3.Invalid，违反 RHAH_PawnFactory.Validate 的地图出生格契约，返回 InvalidRequest。失败清理在同一个地图生成长事件中销毁父物体，早于 Map.FinalizeInit 排队的绘制初始化。MapDrawer.Dispose 访问未创建的 sections，已释放的网格又被排队绘制回调访问 |
| 最小修复 | 空投先按有效出生格创建并建立访客 Lord，再离图装入原版空投舱；WorldObject_RHAH_Approach 在地图生成结束回调中完成原事件执行、玩家入图与失败清理。锁定 arriving 直到回调结束，保留原事件成功后才转移玩家的事务顺序 |
| 明确不做 | 不改变同格菜单条件、世界图标插值、移动路径、原事件态度、地图解析、其它模组补丁和事件权重 |
| Language | 无新增或修改，沿用拦截失败键 |
| 存档 | 无新键、无迁移、无破坏性重建 |
| 归属表 | 不变，原版临时地图父物体和 retainedCaravanData 仍保留 |
| 回归 | 真实程序集复现旧空投请求 InvalidRequest 和未初始化 MapDrawer.Dispose 的 NullReferenceException；隔离 Unity 的烟测通过拦截成功、事件失败、入图前异常、部分入图异常四条路径，以及 I-032/I-046 的出生校验、Lord 建立和空投 payload。现有相关 23 项及全量 433 项测试通过，结构检查和实现构建通过，两个修改文件 LSP 诊断正常 |
| 后续债 | 烟测替换 Unity 图形、完整 Pawn 生成与世界操作边界，不能证明完整模组列表下的实际画面或保存/读档；仍需游戏内复测 |

拦截在地图生成长事件完成队列中，等待原版绘制初始化后再执行原事件与玩家入图。原事件失败时玩家远行队与鼠族事件保留，已初始化的临时地图删除；入图中途异常时保留已放下的玩家成员。没有新增存档键、Language 或 Harmony 补丁。临时烟测脚本验证后删除，不随模组发布。
