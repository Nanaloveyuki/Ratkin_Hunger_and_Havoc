# 队列事件生成失败后无限重试

| 字段 | 内容 |
| --- | --- |
| 复现 | 0.1.0 新游戏。通过 IrisMenus 开发者事件触发 I-002，观察 Player.log；Worker 在生成阶段抛出 `InvalidCastException` 或返回 false 后继续观察队列 |
| 期望 / 实际 | 期望确定失败的事件从队列移除并记录一次错误，实际同一事件反复调用并持续输出 `did not spawn` / `threw while spawning` |
| 版本 | 0.1.0 |
| 级别 | S1 |
| 根因 | 队列把 Worker 的确定失败与“地图尚未可用”混为同一状态，异常和 false 分支都不消费当前队列项，导致每帧重复调用 |
| 最小修复 | 无地图时继续等待；Worker 抛异常或返回 false 时消费当前队列项并记录终止日志；保留已成功事件的正常消费和多人批次延迟登记 |
| 明确不做 | 不改事件 Def、事件点数、API、存档键、批次登记时机或其它事件生成逻辑；不吞掉异常，只终止该队列项 |
| Language | 无 |
| 存档 | 无新键；现有待处理队列语义收紧为终止失败不再保留 |
| 归属表 | 否 |
| 回归 | 队列异常和 false 结果各消费队首一次；无可用地图时仍保留；I-002 多人批次成功后生成并清除队列 |
| 后续债 | 额外规则处理中的 `ObjectiveRef` 空引用需结合完整游戏日志和对应 Mod 版本另行定位，本次不扩大到未确认调用点 |
