# 四个家庭 Job 接到真实行为

| 字段 | 内容 |
| --- | --- |
| 复现 | 新游戏。母亲带着登记过的孩子离场。母亲背包里有食物，孩子饥饿。本模组来源的幼年囚犯饥饿，地上有污物，旁边有睡着、不满 3 岁、仍有鼠尾的囚犯 |
| 期望 / 实际 | 期望离开前先放下仍抱着的孩子。母亲把自己的一份食物交给饥饿的孩子并让其进食。囚犯走到污物上吃掉一点并获得少量营养。咬尾成功时咬掉天然鼠尾，双方得到心情，失败只留咬伤。实际四个 JobGiver 没有调度，Driver 只等待，不放下、不喂、不吃、不咬 |
| 版本 | 0.1.0 |
| 级别 | S1 |
| 根因 | JobDef 和设置已经存在，寻食和囚犯思考树都没有调用。Driver 没有完成文案描述的动作 |
| 最小修复 | 访客寻食在离场前先放下孩子，再给饥饿的已登记孩子喂自己的食物。囚犯在原版进食之后尝试舔污物，再尝试咬尾。放下只处理仍被母亲抱着的孩子。喂食转移一份可吃的食物。舔污物减少一层并加营养。咬尾只打 `RK_BodyPart_Tail`，成功变成缺失部位。失败冷却走已有的一小时食物搜索 |
| 明确不做 | 不搬旧鼠灾的随机污物种类、中毒档位、漂浮文字、社交打架和尾部掉落物。不新增闸门。不改母亲喂食的旧废弃语义 |
| Language | `RHAH_Thought_ScavengedFilth`、`RHAH_Thought_TailBitten`、`RHAH_Thought_BitATail`。设置提示改为实际后果 |
| 存档 | 无新键。ThoughtDef 是新的可进档记忆 |
| 归属表 | 是。三份 ThoughtDef 登记为 Remove |
| 回归 | 放下只在仍被携带时成立。喂食要求母亲持有食物且孩子饥饿。污物按距离入围。咬尾要求天然鼠尾、睡着、不满 3 岁。寻食和囚犯树包含这四个入口 |
| 后续债 | 污物不按种类给不同营养。咬尾不掉落可搬运的尾巴物品 |
