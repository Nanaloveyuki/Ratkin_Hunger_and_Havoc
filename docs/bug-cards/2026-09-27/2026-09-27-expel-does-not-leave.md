# 驱逐工作发出后人不离图

| 字段 | 内容 |
| --- | --- |
| 复现 | 重新编译部署后，殖民者右键在场来客并点「驱逐」。来客态度为中立。另一次对刚被乞讨巴掌打晕的来客做同样操作 |
| 期望 / 实际 | 期望走到身边后这批人离图；打晕的人醒来后再走。实际离场令不发，人留在原地。巴掌默认昏迷 3 小时 |
| 版本 | 0.1.0 |
| 级别 | S1 |
| 根因 | `React` 的第二参数是伤害。中立受击返回 `None`，驱逐才返回 `Leave`。菜单和选择信都把 `forcedAway` 以 `true` 传入，中立驱逐因此直接返回。`OrderLeave` 和离场 Job 又跳过倒地的人，昏迷期间造不出离图 Job |
| 最小修复 | 驱逐调用改传 `false`，伤害仍传 `true`。Lord 已切到离场时，倒地或昏迷的人保留离场状态，醒来后由离场 duty 再给离图 Job。巴掌默认昏迷改成半小时，旧档里仍是 3 的读档后改成半小时 |
| 明确不做 | 不改五档反应表。不把倒地的人立刻抱出地图。不改玩家已经改成其它小时数的设置 |
| Language | 中英击晕说明从默认 3 改成默认半小时 |
| 存档 | `begSlapKnockoutHours` 默认从 3 改成 0。0 表示半小时，旧默认 3 读档后写成 0。其它已保存小时数不改。1.0.0 前不另做迁移 |
| 归属表 | 是。只改这一行的默认说明 |
| 回归 | `ManualExpel_LeavesNeutralWithoutTurningHostile`。中立驱逐是 `Leave`，中立受击仍是 `None`。离场源码不再因倒地直接跳过。默认击晕是半小时 |
| 后续债 | 无 |
