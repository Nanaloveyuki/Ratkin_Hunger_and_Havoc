# 手动驱逐不给殖民者派工作

| 字段 | 内容 |
| --- | --- |
| 复现 | 重新编译部署后，殖民者选中，右键在场来客，点「驱逐{名字}」 |
| 期望 / 实际 | 期望选中的殖民者接到驱逐工作，走到目标身边后再让来客离图。实际菜单点下去不分配任何工作 |
| 版本 | 0.1.0 |
| 级别 | S1 |
| 根因 | 菜单直接调用 `TryShift`。来客自己的离场令即使发出，玩家操控的殖民者也不会走过去 |
| 最小修复 | 新增 `RHAH_Expel`。菜单给选中的殖民者派这个工作，目标是被点的来客。走到接触距离后才 `TryShift`。目标不再是活跃访客、死了或离开地图时工作失败 |
| 明确不做 | 不改五档反应。不改选择信里的整批驱逐。不给不能自己走到出口的幼年补携带者 |
| Language | `RHAH_Job_Expel_Report` |
| 存档 | 新 JobDef `RHAH_Expel`，新驱动 `JobDriver_RHAH_Expel`。无新字段。1.0.0 前不迁移 |
| 归属表 | 是。类型和 Def 都是 Remove |
| 回归 | `ManualExpel_AssignsAWalkJob`。菜单派 `RHAH_Expel`，驱动走到目标后才 `TryShift` |
| 后续债 | 无 |
