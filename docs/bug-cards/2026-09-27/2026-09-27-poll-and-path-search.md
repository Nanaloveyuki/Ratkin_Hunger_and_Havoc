# 轮询和寻路热点

| 字段 | 内容 |
| --- | --- |
| 复现 | 二倍速或三倍速下，地图上同时有未进食访客、赈灾区、饥饿来客，或安居点捕食者。打开带瘟疫恐惧或幼年需求特质的人 |
| 期望 / 实际 | 期望地图扫描按游戏内小时做，寻路失败后等到下一次窗口或地图变化再试。实际 250 tick 大约每秒扫一次：等粮对每个赈灾格寻路，找食物对每个候选寻路，啃食连续三次半径搜索，乞讨和偷背包对每个殖民者寻路，心情遍历全图，瘟疫、粮洞、使团、安居点清场和捕食按 250 到 2500 tick 轮询 |
| 版本 | 0.1.0 |
| 级别 | S1 |
| 根因 | 热路径把“现在能不能走到”放进了每次思考和每个候选。慢状态机用短间隔扫整张图，而不是到期或事件 |
| 最小修复 | 食物、等粮、啃食、乞讨、偷背包的失败冷却改成游戏内 1 小时，成功找到前不再寻路。等粮先按距离选格，只对入围格寻路。找食物先打分，只对前几名寻路。啃食合并为一次植物搜索，墙另一次，并共用冷却。心情只看本 Lord 或本派系，不扫全图。瘟疫、粮洞、使团监视、安居点清场、捕食搜索改成游戏内 2 小时。已有 `nextTick` 的只在到期时工作 |
| 明确不做 | 不把四个家庭 JobGiver 接进调度，也不删它们。不改穗音叙事 Tick 的内部状态机，只拉长仍在轮询的入口。不改事件目录的 1000 tick 入队 |
| Language | 无 |
| 存档 | 无新键。`foodSearchTicks` 和 `predationNextTick` 仍是绝对 tick，旧档会多等最多 2 个游戏内小时。1.0.0 前不迁移 |
| 归属表 | 否 |
| 回归 | 等粮和找食物的寻路次数有上限。啃食和偷窃失败会写冷却。心情源码不再遍历 `AllPawnsSpawned`。慢扫描间隔是 `GenDate.TicksPerHour` 或两倍 |
| 后续债 | 家庭四个 JobGiver 仍无调用方。穗音托管、日记、结局仍由 `GameComponentTick` 每 tick 进入后自行判断到期 |
