# 王国篇来信限穗音叙事者

| 字段 | 内容 |
| --- | --- |
| 复现 | 任意叙事者的游戏中，从设置或 IrisMenus 点击“阅读穗音的来信”，关闭阅读器并继续一个 Tick |
| 期望 / 实际 | 仅穗音叙事者允许启动、发送及答复邀请 / 原实现只检查游戏阶段、内容开关和邀请状态，其他叙事者也可启动 |
| 版本 | 当前 1.0.5 开发工作区，K1 全屏阅读器 |
| 级别 | S2 |
| 根因 | KingdomArcRuntime.CanUse 缺少当前叙事者判定，DrawEntry 只检查是否有游戏 |
| 最小修复 | CanUse 复用 RHAH_EndingRuntime.IsNarrator；DrawEntry 共用 CanUse 隐藏不可用入口 |
| 明确不做 | 不新增自动开局触发、随机触发或叙事者切换扫描，不删除已收到的信件或阅读记录 |
| Language | 无新增或修改 |
| 存档 | 无键或类型变化，无迁移；换走穗音保留实例和阅读状态，换回后恢复主动入口 |
| 归属表 | 更新王国篇运行时条件说明，不改卸载动作 |
| 回归 | 真实程序集 smoke：其他叙事者不能 Open、Reply、Notify；穗音可用；切换走再切回不改变邀请与游标 |
| 后续债 | K2–K5 尚未实现，仍按王国篇原规划推进 |

验证：离线上下文初始化后，旧闸门的回归测试在非穗音判定失败（Expected False / Actual True）；加入闸门后 1 项回归通过。真实 Release 程序集的 Mono smoke 通过穗音→兰迪→穗音切换、Open/Reply/Notify 拦截、邀请及段索引保留、内容开关禁用。未在游戏界面实测隐藏入口
