# 边缘来客够不着赈灾区，幼童模组下也不能自己吃

| 字段 | 内容 |
| --- | --- |
| 复现 | 来客从地图边缘进图。赈灾区在基地里，离边缘超过 40 格，区内有食物。另有启用 Toddlers 的存档，幼童处于可自己进食的阶段 |
| 期望 / 实际 | 全图搜一次赈灾食物，结果按地图缓存。有幼童模组时，能自己吃的幼童去赈灾区，只是吃得慢。没有幼童模组时，原版不能行动的婴儿仍不自己吃。实际曼哈顿距离超过 40 就当走不到，并且倒地的来客一律不取食 |
| 版本 | 1.0.3 源码，未正式发布 |
| 级别 | S1 |
| 根因 | `RHAH_ReliefFood.Reject` 用 40 格曼哈顿距离代替可达性。`JobGiver_RHAH_Feed` 又用 `Downed` 挡住取食。有幼童模组时，能自己吃的幼童仍是倒地状态，于是赈灾取食失败并进入一小时冷却，调度落到乞讨 |
| 最小修复 | 赈灾取食去掉距离上限，全图候选只打分，寻路仍只验前 3 名。食物清单按地图缓存，物品变化、区域改动和相关设置清缓存。有幼童模组且操作阶段至少 1 时，倒地不阻止取食；没有幼童模组仍拒绝倒地 |
| 明确不做 | 不改乞讨、偷窃、啃食的搜索半径和冷却。不改幼童行走、携带和离场。不反射 Toddlers 类型 |
| Language | 无 |
| 存档 | 无新键。食物清单缓存不进存档 |
| 归属表 | 否 |
| 回归 | 规则测试：距离不再单独拒绝；幼童模组下阶段 1 的倒地来客可以取食，没有幼童模组时倒地仍拒绝 |
| 后续债 | 未启动游戏、未部署。缓存只覆盖本模组取食，不改原版食物清单 |
