# 轨道家园刷出远行队，图标挡住穿梭机起飞

| 字段 | 内容 |
| --- | --- |
| 复现 | 奥德赛。玩家家园在轨道层（小行星、轨道飞船）。地图事件仍派出 `RHAH_Approach`，目标写成轨道飞船。远行队图标停在轨道上时，穿梭机选目的地点不到该格 |
| 期望 / 实际 | 默认不在太空家园生成远行队，设置打开后才允许。已经在太空的远行队不挡住穿梭机和运输舱选格。实际 `PickMapId` 把轨道家园当普通家园，`RHAH_Approach.validLaunchTarget=false` 让世界点选取中图标后拒绝起飞 |
| 版本 | 1.0.3 源码，未正式发布 |
| 级别 | S1 |
| 根因 | 走近只认 `IsPlayerHome`，不看行星层是否太空。轨道层没有道路，寻路仍当可走，于是刷出步行队伍。起飞选点先命中动态绘制的世界物体；该物体明确不是合法起飞目标，空格被图标挡住 |
| 最小修复 | 默认拒绝太空层家园；设置打开后才列入候选。已有队伍在太空层时不拦截起飞点击。寻路失败或异常时取消队伍，不把异常抛进 `WorldTick` |
| 明确不做 | 不改地面 4 到 6 格、渡海、到达生成和存档键。不给已在太空的旧队伍自动改道到地面。不改原版穿梭机、运输舱或逆重飞船 |
| Language | 新增 `RHAH_Settings_SpaceApproach` 与 `RHAH_Settings_SpaceApproach_Tooltip`，中英日成对 |
| 存档 | 无新存档键、无迁移。新字段是全局 ModSettings，默认 false，缺键读档保持关闭 |
| 归属表 | 更新。登记 `RHAH_Settings.spaceApproachEnabled` |
| 回归 | 规则测试：太空层默认不可走，开关打开才可走；地面层不受开关影响。点击规则：太空层上的远行队不是起飞目标 |
| 后续债 | 未启动游戏、未部署。无引擎测试不覆盖轨道层寻路和图标命中 |
