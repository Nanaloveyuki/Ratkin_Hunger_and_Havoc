## 偷窃的幼年鼠族

### 背景故事

一群鼠蛋饿得在殖民者的地图里钻进钻出,看见食物就咬,咬到了就往外拖,被人抓住也继续咬那只抓住他们的手.

### 短事件

偷窃的幼年鼠族->概率:野生捕食者

### 长事件

无

### 触发

任意一只活到14岁,并且这一次咬到过食物,或者咬到过人:
- 50% 概率获得: `介个本来就系窝滴` -2心情15天
- 50% 概率获得: `次到惹,泥抓不住` +6心情15天
- 有善良特质时改为前一句, -2心情15天
- 有心理变态或相关原版扭曲类特质,并且这只当时咬到过同族或殖民者时,改为后一句, +6永久心情,并获得食人者特质

没咬到就跑的不记.死在14岁前的不记.
