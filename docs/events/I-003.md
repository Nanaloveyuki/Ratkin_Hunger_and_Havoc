## 耗子分妈

### 背景故事

长期的饥饿促使一只鼠妈的孩子们失去了理智,满脑子只想着饥饿,鼠妈没有找到任何食物,被饥饿冲昏头脑的鼠蛋们开始攻击他们的母亲并啃食,直到每个鼠蛋都吃饱后才拖着他们满身咬伤和流血的母亲来到了殖民者的地图,如果没有及时的救治的话,很可能会因为各种因素离世.尽管这些鼠蛋因为长期的饥饿导致大脑发育不良,他们没有此时的记忆,只认为吃饱了,或许在未来这些鼠蛋想起来时会认为天经地义,又或是崩溃.

### 短事件

耗子分妈->概率:野生捕食者

### 长事件

无

### 约束

横穿地图直接离开不做停留

### 触发

当该事件的任意鼠蛋存活到14岁时:
- 鼠妈已死亡
  - 50% 概率获得: `窝滴妈妈被窝次了,窝好愧疚叽...` -6永久心情, 获得善良特质
  - 50% 概率获得: `窝滴妈妈被窝次了,饿饿就次天经地义吱!` +12永久心情
  - 当存在善良特质时 100% 概率获得: `窝滴妈妈被窝次了,窝好愧疚叽...` -6永久心情
  - 当存在心理变态或相关原版扭曲类特质时 100% 获得: `窝滴妈妈被窝次了,饿饿就次天经地义吱!` +12永久心情, 获得食人者特质
- 鼠妈未死亡
  - 50% 概率获得: `窝对不起窝滴妈妈` -3心情15天, 获得善良特质
  - 50% 概率获得: `饿饿就次次叽!泥看窝滴妈妈还活滴好好滴!` +24心情15天
  - 当存在善良特质时 100% 概率获得: `窝对不起窝滴妈妈` -6永久心情
  - 当存在心理变态或相关原版扭曲类特质时 100% 获得: `饿饿就次次叽!泥看窝滴妈妈还活滴好好滴!` +24永久心情, 并为触发该内容的鼠蛋附加食人者特质

当该事件的任意鼠蛋(14岁以下)死亡时,且鼠妈仍然存活时:
- 鼠妈 50% 概率获得 `咬我的那只臭鼠蛋终于死了吱` +3永久心情
- 鼠妈 50% 概率获得 `我的鼠蛋吱...` -3心情15天

鼠蛋被囚禁或奴役时:
- 分别以 10% 概率获得心情,该心情直到身份发生变化:
  - `坏银, 放鼠鼠窝离开吱!` -4
  - `坏坏! 鼠鼠窝想次糖糖叽!` -4
  - `叽! 窝被抓起来惹...` -2
  - `坏坏! 鼠鼠窝想妈妈惹!` -2
  - `坏银把窝抓起来惹...` -2
  - `坏银, 抓鼠鼠窝...` -2
  - `叽叽, 有次的吱!` +1
  - `窝不要被做成鼠鼠蛋糕吱!` -8
  - `哭哭! 坏坏! 窝被抓了吱!` -6
  - `鼠鼠,窝臭臭! 不好吃!` -8
  - `次糖糖...窝想次糖糖...` -2
